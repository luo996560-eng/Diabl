## 待修

### 2. P1 事件中重新整理會重抽事件
- 現象：事件畫面按 F5 後，同一個月會換一則事件，已顯示的文字消失。
- 原因：`buildSaveObject()` 沒有保存 `currentEvent`；而 `nextMonth()` 第一行就 `saveGame()`，此時新事件尚未產生，所以存檔記的是「上一個月已結算、新事件未定」的狀態。
- 影響：可用重新整理刷事件，等於繞過「已看過的事件」與稀有度控制。
- 修法：在存檔中加入 `eventRef`（事件 id + 月份種子），`loadGame()` 依 id 還原事件；`nextMonth()` 改成產生事件後才存檔。需同步升 `SAVE_VERSION` 並提供遷移。

### 3. P1 存檔版本不符即刪檔
- 現象：`loadGame()` 發現 `version !== SAVE_VERSION` 時，備份後直接刪除存檔並要求重新開始。
- 影響：每次改版只要動到存檔結構，玩家的這一生就沒了。這是目前最大的體驗風險。
- 修法：改成逐欄位補齊的軟升級（缺欄位給預設值），只有結構真的不相容才備份並提示。備份已存在，可作為救援入口。

### 4. P2 成就名稱重複 45 組
- 現象：1,000 項成就的 `id` 全部唯一，但有 45 組 `name` 完全相同（例：「大成魔頭・5」「江湖浪子・3」）。
- 影響：成就列表會出現看起來一樣的兩項，難以辨識；不影響解鎖判定。
- 修法：為重複名稱加上區分後綴（來源、門檻或層級）。

### 5. P2 謎題重複 1 則
- 現象：53 則謎題中有 1 組題面完全相同。
- 影響：連續遇到時會覺得重複。
- 修法：改寫其中一則。

### 6. P2 手機無法縮放
- 現象：`<meta name="viewport">` 含 `maximum-scale=1,user-scalable=no`。
- 影響：視力不佳或需要放大文字的玩家無法縮放；也是無障礙問題。
- 修法：移除這兩個限制，改以固定版面控制。
